# Windows kurulum paketi

`woodmood-pc-setup.zip` dosyasını açıp GitHub sayfasındaki **Download raw file** düğmesiyle indirin.

Paketi çıkardıktan sonra `woodmood-social/docs/WINDOWS_SETUP.md` dosyasındaki adımları izleyin.

Paket kaynak kod ve Windows başlatıcılarını içerir; parola, gerçek token, tarayıcı profili, .env veya kullanıcı veritabanı içermez.

Aynı klasörde SHA-256 doğrulama dosyası bulunur.
